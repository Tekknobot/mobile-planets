# Planet War Prototype

Godot 4.6.2 procedural pixel planet war sandbox.

## Core controls
- Drag the planet to rotate it.
- Hold the planet briefly to open the radial action menu.
- Choose WAR, then select one of your cyan faction nodes followed by an enemy node.
- Enemy factions automatically retaliate after each player strike when they still have a viable launch site.
- Missile type escalates with planetary tension.
- Mouse wheel retains zoom on desktop.

## World generation
Every generated planet now contains native alien life and a technological civilization, including desert, ice, gas giant, and lava worlds. Each world automatically receives a player faction and one or two hostile factions.
